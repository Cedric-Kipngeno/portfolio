# Cedric Kipngeno — Developer Portfolio

Personal developer portfolio built with **React 18** and **Vite**, showcasing my web, mobile (Kotlin Android), backend (Flask & MySQL), and AI/Data Science projects synced live with the GitHub API (`@Cedric-Kipngeno`).

## Tech Stack
- **Frontend:** React, Vite, Modern CSS
- **Live Data:** GitHub REST API integration (`users/Cedric-Kipngeno/repos`)

## Getting Started

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```
